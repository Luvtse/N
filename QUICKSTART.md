# 🚀 NIDAW Quick Start (3 Minutes)

## Prerequisites
- Docker & Docker Compose
- Go 1.21+
- Flutter 3.16+
- Make

## Setup

```bash
# 1. Clone and setup
git clone https://github.com/your-org/nidaw.git
cd nidaw
make setup

# 2. Start all services
make dev

# 3. Seed test data
make seed

# 4. Run tests
make test

# 5. View logs
make logs
