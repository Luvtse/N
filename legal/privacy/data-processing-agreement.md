# NIDAW Data Processing Agreement (DPA)

**Effective Date:** [Date]

This Data Processing Agreement ("DPA") is entered into between **NIDAW Inc.** ("Processor") and **[Customer Name]** ("Controller") for the processing of personal data in connection with the NIDAW platform services.

## 1. Definitions
- **"Personal Data"** has the meaning given in applicable data protection laws (e.g., GDPR Art. 4).
- **"Processing"** means any operation performed on Personal Data (collection, storage, use, disclosure, etc.).
- **"Data Subject"** means the individual whose Personal Data is processed.
- **"Sub-Processor"** means a third party engaged by Processor to process Personal Data.

## 2. Scope and Purpose
Processor processes Personal Data on behalf of Controller for the following purposes:
- Providing NIDAW mobility, accommodation, and delivery services.
- Processing payments and managing transactions.
- Communicating with Data Subjects (notifications, support).
- Analytics and platform improvement (anonymized).
- Compliance with legal obligations.

## 3. Obligations of the Processor
### 3.1 Processing Instructions
Processor shall process Personal Data only on documented instructions from Controller, unless required by law.

### 3.2 Confidentiality
Processor ensures that personnel authorized to process Personal Data are bound by confidentiality obligations.

### 3.3 Security Measures
Processor implements appropriate technical and organizational measures (Art. 32 GDPR), including:
- Encryption (AES-256 at rest, TLS 1.3 in transit).
- Access controls and authentication (MFA, RBAC).
- Regular security testing and audits.
- Incident response procedures.

### 3.4 Sub-Processing
Processor shall not engage Sub-Processors without prior written consent from Controller. A list of current Sub-Processors is maintained at [URL].

### 3.5 Data Subject Rights
Processor assists Controller in responding to Data Subject requests (access, rectification, erasure, portability, restriction, objection).

### 3.6 Data Breach Notification
Processor notifies Controller without undue delay (and within 72 hours) upon becoming aware of a personal data breach.

### 3.7 Data Protection Impact Assessment (DPIA)
Processor assists Controller in conducting DPIAs where required.

### 3.8 Prior Consultation
Processor assists Controller in prior consultations with supervisory authorities.

### 3.9 Deletion or Return of Data
Upon termination, Processor deletes or returns all Personal Data to Controller (unless retention is required by law).

### 3.10 Audits and Inspections
Processor makes available to Controller all information necessary to demonstrate compliance and allows audits/inspections.

## 4. International Transfers
For transfers outside the EEA, Processor relies on:
- Adequacy decisions.
- Standard Contractual Clauses (SCCs).
- Binding Corporate Rules (if applicable).

## 5. Duration and Termination
This DPA remains in effect for the duration of the services agreement and survives termination for the period required by law.
